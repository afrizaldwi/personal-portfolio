# Portfolio repository

- Keep React, Vite, JavaScript, Tailwind CSS and DaisyUI. Prefer existing dependencies and component boundaries.
- Give every component file one primary component. Keep content in its owning data module and pages focused on composition.
- Keep changed components and pages near 100 lines. Review components over 150 lines and keep utilities and data modules focused.
- Publish only evidence-backed claims and approved assets. Keep public interface copy in English.
- Run npm lint, build and Git whitespace checks after changes. Use npm.cmd on Windows.
